How It Works

1
Create tunnel on this server
Click "Create Tunnel" to expose a local port through an encrypted secure tunnel.
2
Install the FireSDN Access Client on your device
The device you're connecting FROM needs the FireSDN Access Client to route traffic through the secure tunnel.
# Linux / Debian
curl -L --output firesdn-access.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb && sudo dpkg -i firesdn-access.deb
macOS: brew install cloudflare/cloudflare/cloudflared  |  Windows: download from the GitHub releases page
3
Connect using the generated SSH command
Each tunnel generates a ready-to-use SSH command — just copy and paste it on your client machine.
Security

All traffic is TLS-encrypted through an encrypted global relay network. Tunnels are ephemeral — they disappear when stopped. Your local service is never exposed directly to the internet.
